# Nautilus-Nitrox-Fix
I made Nautilus 1.0.0-pre.50 work with Nitrox 1.8.1.0 for my partner and I to play, we were getting the "Stuck on epilepsy warning". Now it works and I've no clue what I'm doing with GitHub, just trying to make it available to others. Beware what mods you put on, they can still break the game as Nitrox did not build mod compatibility.
